# 2026-10-31

## 卷轴系统「指令反馈」策略可配置化（v2.6.4）

**问题**：`scroll-engine.js` 的 `handleServerStart` + `server.js` 启动回调都会无条件下发 `gamerule sendCommandFeedback false`，导致没有卷轴的插件服/模组服也被强制静默，部分插件与模组功能异常。

**改动**
- `scroll-engine.js`
  - 新增实例级设置：`instances/<instanceId>/scrolls/settings.json`，字段 `commandFeedback`（`auto` | `silent` | `native`，默认 `auto`）+ 内部标记 `panelSilenced`、`legacyHealed`。
  - 新增方法：`getInstanceSettingsFile` / `getInstanceSettings` / `saveInstanceSettings` / `setInstanceRuntimeFlags` / `countEnabledScrolls` / `shouldSilenceCommandFeedback` / `applyCommandFeedback` / `reevaluateCommandFeedback` / `getFeedbackRuntime`。
  - `handleServerStart` 改为按策略应用；`auto` 模式随卷轴增删（toggle / delete / install）动态重算。
  - 新 REST：`GET /api/scrolls/settings`、`POST /api/scrolls/settings`（必须注册在 `/:id/*` 之前）。
- `server.js`：删除启动成功时硬编码写 `sendCommandFeedback false` 的两行。
- 前端 `ScrollManager.js`：页头新增「系统设置」齿轮按钮 + 设置弹窗（三选一策略卡片、运行状态三宫格、插件/模组服风险提示、保存即热生效）。
- `public/css/style.css` 末尾新增「卷轴系统设置对话框」样式块（`.scroll-sys-*`），全部走主题变量，含 `scrollSysOptionIn` / `scrollSysDotIn` 动画与 `prefers-reduced-motion` 适配。
- `i18n.js` 新增 `scrolls.sys_*` 与 `scrolls.feedback_*` 中英文词条。

**注意（重要约定）**
- 组件 `setup()` 内不能用 `$t`（它只是 `app.config.globalProperties`），需 `import { createI18n }` 后 `const t = createI18n(store)`。
- 旧版本已在世界存档写入 `sendCommandFeedback=false`，故加了 `legacyHealed` 一次性纠偏：升级后首次启动若无需静默会恢复 `true` 并落盘标记。
- `native` 模式绝不触碰 gamerule；仅回滚面板自己造成过的静默。
- 版本号已提升至 2.6.4，`index.html` 的 `style.css` / `app.js` 缓存版本同步到 `?v=2.6.4`（改前端资源记得同步）。

**验证**：临时脚本（已删除）跑了 16 项策略逻辑断言 + 12 项 express 路由集成断言全部通过；用 headless Chrome 出图核对明暗主题（预览文件留在 `scratch/ui-preview/`）。
