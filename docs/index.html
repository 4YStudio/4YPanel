核心特性

为专业 Minecraft 运维而打磨

从底层内存压减到直观控制台，从自动化依赖解析到无损备份恢复，提供行云流水般的开服体验

极致内存压减与背压流控

面板闲置常驻内存仅约 70MB（峰值稳定 < 100MB）；Sharp 原生 C++ 缓存压减 90%，切片合并全程受 Backpressure 背压控制，大文件合并内存锁死在 <10MB，杜绝 OOM；支持 --no-cluster 单进程超低配模式。

资源下载与前置联动解析

重构 Modrinth 资源下载器，覆盖插件、模组、数据包、资源包四大分类；支持必要前置多层递归解析、防死循环与已安装模组智能跳过。

实时性能监控看板

实时采样服务器 CPU、内存使用曲线，即时查看在线玩家名单与头像；WebSocket 极速双向流，万级日志平滑缓冲无卡顿渲染。

文件管理与原生解压

支持多文件在线上传下载、高亮编辑器与文本搜索定位；集成原生系统级 unzip / tar 流式高保真还原，保留 POSIX 权限与软链接。

内置 FRP 内网穿透

集成轻量 FRP 穿透客户端，无需公网 IP 与路由器端口映射；支持自动重连与节点测速，朋友随时随地快速联机。

安全防护与 2FA 认证

基于 TOTP 算法支持 Google Authenticator 等双重身份验证器；支持 CLI 快捷重置密钥、密码盐值加密与敏感目录权限隔离。

Server.properties 可视化中心

中文友好的全景参数配置中心，针对 Vanilla、Paper、Fabric 自动展示专属优化建议，参数修改即时生效。

安全备份与多方案快照

多维备份系统，支持整服打包、独立地图备份与核心模组备份；备份包结构安全过滤，一键安全回滚世界进度。

全链路移动端深度重构

对手机端与平板端进行地毯式 UI/UX 优化，重新编排控制台、资源下载筛选、安装向导与属性管理器，单手即可轻松开服。

# 修改监听地址与端口

# 重启面板 / 停止服务 / 重置 2FA 密钥
./MWP-linux-amd64 restart
./MWP-linux-amd64 stop
./MWP-linux-amd64 reset
